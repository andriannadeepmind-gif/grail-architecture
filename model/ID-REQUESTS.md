# ID-REQUESTS — τα IDs που ζητούνται, κανένα δεν δημιουργήθηκε

Copyright (c) 2026 STAVROPOULOS LAW. All Rights Reserved.

**Κατάσταση: αναμένει τον δημιουργό.** Κατά τον **κανόνα 1** του `docs/architecture-draft/spine-vocab.md`, δεν επινοείται ID. Είχα επινοήσει **53**· αφαιρέθηκαν όλα από τα αρχεία του `model/` και καταγράφονται εδώ ως αιτήματα. Τα στοιχεία κρατούν περιγραφικά ονόματα, **όχι έδρες**, μέχρι να εγκριθούν ή να απορριφθούν.

## Α. Νέες έννοιες που δεν έχουν έδρα στα 76 CMP / 32 ICD / 40 INV

| Ζητούμενο | Τι είναι | Γιατί δεν καλύπτεται |
|---|---|---|
| Πύλη εισδοχής ισχυρισμού | Το T6 ως πύλη σε ό,τι το σύστημα **δέχεται**, όχι μόνο σε ό,τι λέει | Το ICD-30 επαληθεύει ισχυρισμό κατ' αίτηση· δεν φυλάει την είσοδο |
| Successor Compiler | Το T8: ο πυρήνας μεταγλωττίζει τον διάδοχό του, με ανάλυση απώλειας και τρίπτυχη ετυμηγορία ταυτότητας | Το CMP-AEO-06 αντικαθιστά **όργανο** υπό σταθερό metamodel |
| Όργανο διακριτότητας | Το T3: διακριτότητα **μεταξύ** οντοτήτων | Η Battery μετρά συνέχεια **εντός** οντότητας (Δ-0) |
| Έλεγχος μονοπατιών αποτελέσματος | Στατική απαρίθμηση κάθε διαδρομής προς τον κόσμο· παράγει το `unmediatedEffectPaths` του T9 | Κανένα από τα 76 δεν απαριθμεί μονοπάτια |
| Σαρωτής περιβάλλοντος | Αναδρομική σάρωση, spawn scouts, χαρτογράφηση Unknown | Το CMP-COG-11 είναι αντίληψη εγγράφων· δεν κυνηγά |
| Πρωτόκολλο scouting | Οι μόνιμες διαταγές: βάθος, συχνότητα, κλιμάκωση | Δεν υπάρχει |
| Δείκτης επιστημικού ρίσκου | Μετρημένη έκταση του μη χαρτογραφημένου | Δεν υπάρχει |
| Περιοχή Unknown | Το άγνωστο ως **λίστα** αντί για αίσθημα, ώστε η κάλυψη να μετριέται | Δεν υπάρχει |

## Β. Δομές που η ύλη απαιτεί και το σώμα δεν έχει

| Ζητούμενο | Τι είναι |
|---|---|
| Διάνυσμα κατάστασης 10 αξόνων | Ρητή απαγόρευση συμπίεσης σε αριθμό· η ολικά διατεταγμένη κλίμακα δεν εκφράζει «αυθεντική πηγή αλλά παρωχημένη» |
| Πύργος meta-επιπέδων | Ο `+META-LEVEL-RULES+` του δημιουργού: default deny, χωρίς υπερπήδηση, δηλωμένος λόγος ανόδου. Το `gap/EVO.md` το ζητά ονομαστικά ως απόν |
| Ένας φάκελος (invariant) | Ρητή απαγόρευση δεύτερου envelope |
| Συμβόλαιο Organ ABI | Τα 17 πεδία με νόμο ανά πεδίο, συν τα πέντε που λείπουν |
| InstitutionalAct ως όψεις | Το Cognitive Object v2 και το proof-carrying object ως όψεις του ενός |

## Γ. Κλιμακωτή αυτονομία, meta-bounds, σημείο απόφασης

| Ζητούμενο | Τι είναι |
|---|---|
| Επιστημικό συμβόλαιο | Οι πέντε όροι της αυτόνομης δράσης |
| Κανόνες αυτονομίας (4) | Δεν πράττει χωρίς απάντηση· αναστρεψιμότητα που δεν αποδεικνύεται μετράει ως μη αναστρέψιμη· αντίστροφο βήμα έτοιμο πριν· η έγκριση ποτέ ως reward ή fitness |
| Πάγωμα χρόνου | Αναστολή εξωτερικών αποτελεσμάτων όσο εκκρεμεί η υπογραφή |
| Hot-swap ως πράξη | Περνά το ίδιο συμβόλαιο, με τον πρόγονο εκτελέσιμο |
| Όριο μηχανισμού (4) | Προέλευση, αναπαραγωγή, ετικέτες ροής, πλήρης καταγραφή — δεν κάμπτονται |
| Όριο πολιτικής | Πεδίο κόστους αντί για τοίχο |
| Απόδειξη διέλευσης | Παράγεται από τον αντίπαλο, όχι από τον προτείνοντα |
| Λήξη διέλευσης | Δεν γίνεται ποτέ προηγούμενο |
| Έδρα απόφασης (PDP) + 3 κανόνες | Αυτονομία, εμβέλεια, διέλευση — **όλοι εκτός πυρήνα** |
| Εγγραφές πολιτικής (5) | Φάκελος κόστους/χρόνου· απαγόρευση πιθανότητας έκβασης· σημείο απόφασης· παραχώρηση αυτονομίας· εξουσιοδότηση πρόσβασης |
| Κανόνες βαθμολόγησης (3) | Ανθρώπινη βεβαίωση δεν είναι επιτυχία· κατευθυνόμενη γένεση δεν είναι αυτόνομη· margins προκαταχωρισμένα |
| Δοκιμές επαλήθευσης (9) | Μία ανά T, που δένει την απαίτηση με το όργανο |
| Μέριμνα κυριαρχίας | Μόνο ο δημιουργός εγκρίνει |

---

**Σύνολο: 53.** Κανένα δεν ισχύει μέχρι να το εγκρίνεις. Όπου απορρίψεις ένα, το αντίστοιχο στοιχείο του `model/` φεύγει ή συγχωνεύεται σε υπάρχουσα έδρα.

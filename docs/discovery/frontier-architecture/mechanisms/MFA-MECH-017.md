# MFA-MECH-017 — Critical-Pair Evolution Gate (CPEG): στατικός έλεγχος αμφισημίας πριν από κάθε προαγωγή

| Πεδίο | Περιεχόμενο |
|---|---|
| **1. ID** | MFA-MECH-017 |
| **2. Όνομα** | Critical-Pair Evolution Gate |
| **3. Ικανότητα** | MFA-CAP-025, 026, 055· χρησιμοποιείται από ORP, GCP, PATCH-PROTOCOL |
| **4. Πρόβλημα** | Το ORP ελέγχει ένα νέο όργανο ΜΟΝΟ του (shadow/differential)· δεν ελέγχει αν η **συνύπαρξή** του με τα υπάρχοντα δημιουργεί αμφισημία (δύο κανόνες που ταιριάζουν στο ίδιο και δίνουν άλλο αποτέλεσμα ανάλογα με τη σειρά). MATERIAL §9.6 «κρυφή σύζευξη»· CLAIMS F46 (αντιφάσεις που επιβίωσαν στη σύνθεση). Κανένα ORP/feature-flag σύστημα δεν αποδεικνύει σύγκλιση της σύνθεσης. |
| **5. Πρώτη αρχή** | Αν οι κανόνες του συστήματος (σχήματα CC, κανόνες οργάνων, patches) είναι κανόνες επανεγγραφής γράφου, τότε η αμφισημία της συνύπαρξης είναι **αποφασίσιμη τοπικά**: υπολογίζονται τα κρίσιμα ζεύγη (ελάχιστες επικαλύψεις δύο αριστερών πλευρών) και ελέγχεται αν ενώνονται (joinable). Μη ενώσιμο ζεύγος = δηλωμένη αμφισημία που απαιτεί σειρά προτεραιότητας ή διαχωρισμό υπογραφημάτων — ποτέ σιωπηλή. |
| **6. Οντολογία** | `Rule r: L ← K → R` με τύπους (MFA-ALT-5)· `CriticalPair⟨r_i, r_j, overlap O, result_i, result_j, joinable: bool∣UNKNOWN(budget)⟩`· `Resolution ∈ {PRIORITY(order), PARTITION(subgraph), REJECT}`· `Gate report` |
| **7. Κατάσταση** | Μητρώο ενεργών κανόνων· cache κρίσιμων ζευγών (invalidated σε κάθε ADD/MODIFY) |
| **8. Είσοδοι/έξοδοι** | Είσοδος: υποψήφιος κανόνας/όργανο/patch· Έξοδος: PASS (όλα joinable) ∣ REPORT (λίστα μη ενώσιμων με προτεινόμενη Resolution) ∣ UNKNOWN(UNDECIDABLE_IN_BUDGET) για ζεύγη που δεν αποφασίστηκαν |
| **9. Αλγόριθμος** | (1) Για νέο `r'`, για κάθε ενεργό `r_i`: υπολογισμός όλων των ελάχιστων επικαλύψεων `O` των `L'` και `L_i` (τυποποιημένο matching — τα L είναι μικρά εκ κατασκευής, §MFA-ALT-5 §4)· (2) Εφαρμογή `r'` μετά `r_i` και `r_i` μετά `r'` στο `O`· (3) Έλεγχος joinability (ίδιο αποτέλεσμα μετά από περαιτέρω επανεγγραφές, με βάθος-budget)· (4) Μη ενώσιμο → Resolution: αν οι κανόνες ανήκουν σε διαφορετικά υπογραφήματα τύπων → PARTITION (δηλωμένη)· αν ίδιο → PRIORITY απαιτεί απόφαση (Court/δημιουργός, ποτέ αυτόματη)· (5) UNKNOWN ζεύγη καταγράφονται ως voids (002) και **μπλοκάρουν** την προαγωγή σε Tier-0/1 υπογραφήματα (fail-closed), επιτρέπουν σε Tier-2 με σήμανση· (6) Το report είναι δέσμευση· η προαγωγή αναφέρει το CID του |
| **10. Διεπαφές** | `CPEG.check(rule')→Report` · `CPEG.resolve(pair, resolution, decision_cid)`· καλείται από ORP.Propose, PATCH-PROTOCOL §4 βήμα 6, GCP compile |
| **11. Εξαρτήσεις** | MFA-ALT-5 (κανόνες ως DPO), MFA-MECH-001 (Schemas), 002 (voids) |
| **12. Πόροι** | O(|rules| · |overlaps|)· με μικρά L: ms–s· budget ανά ζεύγος |
| **13. Κλιμάκωση** | Incremental: μόνο ζεύγη με τον νέο κανόνα· cache |
| **14. Αποτυχίες** | Κανόνας με μεγάλο L → πολλές επικαλύψεις → budget → UNKNOWN (ορατό)· η λύση είναι μικρότεροι κανόνες, όχι παράκαμψη |
| **15. Αντιπαλικοί** | Κανόνας σχεδιασμένος να «κρύβει» επικάλυψη (τύποι που φαίνονται διαφορετικοί) → η επικάλυψη υπολογίζεται στη δομή τύπων, όχι σε ονόματα· «rule bombing» → budget + Court για ADD κανόνων Tier-0/1 |
| **16. Επαλήθευση** | VO: 0 προαγωγές σε Tier-0/1 με UNKNOWN/μη ενώσιμα ζεύγη· mutation: εισάγω δύο σκόπιμα αντιφατικούς κανόνες → REPORT υποχρεωτικό· RDM-E3 |
| **17. Πρωτότυπο** | F1: critical pairs των 8 σχημάτων CC (χειροκίνητα/Lean)· F2: εργαλείο πάνω στους κανόνες YAML του πακέτου (patches ως κανόνες) |
| **18. Ελάχιστο πείραμα** | 8 CC σχήματα + 5 κανόνες οργάνων + 3 patches: πλήρης πίνακας κρίσιμων ζευγών, joinability, χρόνος |
| **19. Διάψευση** | Αν οι κανόνες των οργάνων δεν εκφράζονται ως DPO με μικρά L (π.χ. όργανα με ολιστική συμπεριφορά) → ο CPEG καλύπτει μόνο τα Schemas και τα patches (δηλωμένο εύρος), και τα όργανα ελέγχονται μόνο δυναμικά (ORP) |
| **20. → Παραγωγή** | Δόση 1 (patches του πακέτου = πρώτοι κανόνες), Δόση 2 (ORP) |
| **21. Εξέλιξη** | Νέος τύπος Resolution = ADD |
| **22. Αλληλεπιδράσεις** | PATCH-PROTOCOL βήμα 6· ORP· GCP· MATERIAL §9.6 hidden coupling (στατικό μέρος)· cockpit: μη ενώσιμα ζεύγη ως ρήγματα μεταξύ κανόνων |

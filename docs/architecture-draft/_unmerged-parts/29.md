## 29. Traceability Matrix — Telos → Requirement → Component → Interface → Invariant → Test → Evidence

Έδρα: το canonical model (`model/grail-world-os.sysml`: `#derivation` Telos→REQ, `satisfy` REQ→CMP, ports/interfaces CMP→ICD, `assert constraint` →INV, `verify` Test→REQ). Αυτός ο πίνακας είναι η προβολή του. Μετά το gate του GP-0 **παράγεται** από το `tools/archgen` και ο πίνακας εδώ αντικαθίσταται από την παραγόμενη έκδοση (`verification/TRACEABILITY-MATRIX.md`). Το αντίστροφο δεν επιτρέπεται.

**Μέθοδοι επαλήθευσης:** A Analysis · I Inspection · D Demonstration · T Test · F Formal proof · M Model checking · S Simulation. **Evidence:** υπογεγραμμένη, content-addressed αναφορά `EV-<test>-<run>` για κάθε test της γραμμής, αποθηκευμένη στο CAS και καταχωρισμένη στο ledger. Η στήλη δείχνει το κύριο evidence id. Όλα τα T1–T9 προκύπτουν από το T0.

**Κανόνες ορφανών (ελέγχονται από το VT-901):**

1. Κάθε REQ έχει ≥1 Telos, ≥1 CMP, ≥1 ICD, ≥1 test και evidence.
2. Κάθε CMP, ICD, INV, VT, KT και EXP εμφανίζεται σε ≥1 REQ.

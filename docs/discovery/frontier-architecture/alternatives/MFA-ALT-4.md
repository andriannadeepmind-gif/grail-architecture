## 1. Η διαδικασία ως μηχανή καταστάσεων

| Κατάσταση | Είσοδος | Ποιος | Έξοδος | Αποτυχία |
|---|---|---|---|---|
| `FILED` | Claim/Motion με standing (capability token που καλύπτει το αντικείμενο) | μέρος (όργανο, οντότητα, Principal) | docket entry με CID | χωρίς standing → `DISMISSED` με λόγο |
| `ADMITTED` | έλεγχος jurisdiction + admissibility (σχήμα, ετικέτα untrusted → όχι ως τελεστής) | registry (kernel) | admission record | ανεπίδεκτο → `DISMISSED` |
| `DISCOVERY` | αιτήσεις μαρτυρίας, subpoenas προς όργανα | μέρη | evidence items με attestation | μαρτυρία χωρίς attestation → μη αποδεκτή |
| `HEARING` | επιχειρήματα, αντεπιχειρήματα (ASPIC+), εξέταση | μέρη + αντίδικος (ADV) | argument graph | timeout → Unknown, ποτέ default judgment |
| `VERDICT` | standard of proof ανά τύπο (Carneades: scintilla / preponderance / clear-and-convincing / beyond-reasonable-doubt ↔ Tier) | τριμελές panel: ≥1 μη-LLM oracle | Verdict + dissent | διαφωνία panel → `Both` και έφεση αυτόματη |
| `APPEAL` | εντός παραθύρου, από μέρος με standing | ανώτερο δικαστήριο / δημιουργός | επικύρωση/ανατροπή· ανατροπή διαδίδει taint | — |
| `EXECUTION` | τελεσίδικο | εκτελεστής με receipt | Effect με προ-δεσμευμένο αντίστροφο | αδυναμία αντιστρόφου → απαιτεί ρητή H1 άδεια |

**Standard of proof ↔ Tier:** Tier-0 πράξεις (σύνταγμα, verifiers, κλειδιά) απαιτούν beyond-reasonable-doubt = proof με ανεξάρτητο kernel· Tier-1 clear-and-convincing = certificate/solver· Tier-2 preponderance = differential/N-version. Έτσι η κλίμακα DEC-X-08 γίνεται νομικός κανόνας.

**Μηχανισμός κινήτρων (mechanism design).** Κάθε μέρος καταθέτει stake (budget)· η διάψευση αμείβεται (bounty), η ψευδής κατάθεση χάνει stake· ο αντίδικος-verifier παίζει παίγνιο μηδενικού αθροίσματος με τον προτείνοντα — η ισορροπία λύνεται με γραμμικό προγραμματισμό σε πολυωνυμικό χρόνο (CLAIMS-VERDICT F65). Το Coordination Market του corpus γίνεται δικαστικό ταμείο.

## 2. Πώς καλύπτονται τα concerns

| Concern | Στην πολιτεία |
|---|---|
| Εξουσία | standing + jurisdiction· τριαδική (ποιος, έναντι ποιου, ως προς τι) + χρονικό παράθυρο = ακριβώς capability token (CLAIMS F69) |
| Θεσμική εκδίκαση | ΕΙΝΑΙ η αρχιτεκτονική |
| Effects | μόνο τελεσίδικες αποφάσεις εκτελούνται· ο κατάλογος F16 («ποιες ενέργειες απαιτούν ανθρώπινη έγκριση») = ποιες υποθέσεις έχουν τον δημιουργό ως υποχρεωτικό δικαστή |
| Αμφισβητησιμότητα | έφεση εγγενής |
| Εξέλιξη | τροποποίηση με ειδική πλειοψηφία και επικύρωση |
| Συλλογικό | conflict of laws· νομολογία ως κοινή μνήμη· dissent διατηρείται |
| Ταυτότητα | νομικό πρόσωπο με charter· η συνέχεια = διατήρηση δικαιωμάτων/υποχρεώσεων (ανεπίλυτες υποθέσεις μεταφέρονται) |
| Unknown | verdict `Unknown(reason)` είναι νόμιμη έκβαση (non liquet) με υποχρέωση επανεξέτασης όταν εμφανιστεί νέα μαρτυρία (σχέδιο παρατήρησης = «τι μαρτυρία θα άνοιγε την υπόθεση») |
| Νομική | το σύστημα ΜΙΛΑ τη γλώσσα του πεδίου του: κάθε νομικό παραδοτέο είναι διαδικασία με receipts |
| Cockpit | docket = η κύρια όψη· χρόνος = ημερολόγιο δικαστηρίου |

## 3. Τι κάνει ανώτερα

- **Νομιμότητα και αμφισβητησιμότητα εκ κατασκευής** — καμία πράξη χωρίς διαδικασία, καμία διαδικασία χωρίς έφεση.
- **Ο κατάλογος F16 γίνεται δομή**: όχι «ποιες αποφάσεις είναι κρίσιμες» αλλά «ποια δικαστήρια έχουν τον δημιουργό ως δικαστή».
- **Η κλίμακα απόδειξης είναι standard of proof** — ο δικηγόρος την καταλαβαίνει χωρίς εξήγηση.
- **Τα κίνητρα είναι μηχανισμός**, όχι ευχή: η επαλήθευση πληρώνεται.

## 4. Τι ΔΕΝ κάνει — τίμια

- **Latency**: κάθε αλλαγή ως διαδικασία με discovery/hearing είναι αργή· ασύμβατη με lean profile και με «σκέψη» (η σκέψη δεν είναι διαδικασία).
- **Αντίληψη, μνήμη, αναζήτηση** δεν είναι διαδικασίες — χρειάζονται άλλο plane.
- **Overhead**: registry, dockets, stakes για κάθε μικρή πράξη.
- **Δεν λέει πώς παράγεται ένα καλό επιχείρημα** — μόνο πώς κρίνεται.

## 5. Τι κλέβει η σύνθεση

(α) **Η μηχανή καταστάσεων της διαδικασίας** για κάθε Effect και για το Court (MFA-CAP-021, MFA-CAP-052)· (β) **standing/jurisdiction ως τα δύο πεδία κάθε capability token**· (γ) **standard of proof ↔ Tier** ως η νομική διατύπωση της κλίμακας DEC-X-08· (δ) **τροποποίηση με ειδική πλειοψηφία Πολιτισμών + επικύρωση δημιουργού** ως ο μηχανισμός εξέλιξης του συντάγματος· (ε) **LP-λυμένο παίγνιο μηδενικού αθροίσματος** για τον αντίδικο-verifier· (στ) **non liquet ως νόμιμο Unknown** με υποχρέωση επανεξέτασης.
